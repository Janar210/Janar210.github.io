# janar210.github.io

Portfolio website of Janarthanan Narayanasamy, served at https://janarthanan.is-a.dev.

The site is built automatically from a private source repository and published to the
`gh-pages` branch of [Janar210/Janar210](https://github.com/Janar210/Janar210). The workflow in
`.github/workflows/deploy.yml` copies that build to GitHub Pages every hour (and can be run by
hand from the **Actions** tab). Nothing needs to be edited here.
